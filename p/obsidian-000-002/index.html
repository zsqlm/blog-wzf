Image Converter安装

插件安装

  • 安装：设置 → 社区插件 → 关闭安全模式 → 搜索 Image Converter → 安装并启用。
  • 配置：
    • 打开插件设置，找到 Drop/paste presets，选 WebP 75（质量 75，可改 1–100）。
    • 可选：设置默认保存路径（如 assets/）、是否删除原图。
  • 使用：直接拖拽 / 粘贴 PNG/JPG，插件自动转成 WebP 并插入。

批量转换存量图片

  1. 安装 Image Converter。
  2. 在文件浏览器里选中要转换的 PNG/JPG 文件夹。
  3. 右键 → Convert to WebP，一键批量转换并自动更新笔记内引用。

优势与注意

  • WebP 比 PNG 小 50–70%、比 JPG 小 25–50%，大幅减小库体积、提升同步速度。
  • 所有主流系统（Windows/macOS/ 移动端）和现代浏览器都支持 WebP。
  • 若需兼容老旧设备，可保留少量高重要性图片为 PNG/JPG。

Image Converter如何设置

1. 打开设置入口

  • Obsidian 按 Ctrl+,（设置）→ 左侧「第三方插件」→ 找到 Image Converter → 点 Options（选项）。

2. 核心设置（必改）

① Drop/paste presets（拖拽 / 粘贴预设）

  • Default preset（默认预设）：选 WebP 75（没有就新建一个）
  • 点 Add new preset → 命名：WebP 75
    • Output format：WebP
    • Quality（质量）：75（推荐 70–85，平衡画质 / 大小）
    • Resize mode：None（不强制缩，需要再开）
    • 其他默认即可。

② Folder（保存位置）

  • Root folder（根目录）：建议填 assets/images（先手动建好这个文件夹）
  • 下方 Use root folder：开启（所有图片统一放这里）

③ Filename（命名规则）

Template：推荐填

1

{notename}-{timestamp}

效果：当前笔记名-时间.webp，不重名、好管理。

④ Link format（插入格式）

  • Link format：选 Wiki link（![[path]]）（Obsidian 原生格式）
  • Path format：Relative（相对路径）

3. 常用开关（建议全开）

在设置页往下滑，开启：

  • Convert on paste：粘贴自动转 WebP
  • Convert on drop：拖拽自动转 WebP
  • Delete original after conversion：转换后删除原图（干净）
  • Auto-update links：移动图片后自动更新引用

4. 批量转换旧图

  1. 在文件浏览器选中要转的 PNG/JPG 文件夹
  2. 右键 → Convert to WebP
  3. 等待完成，插件会自动更新笔记里的图片链接

5. 测试是否生效

  1. 随便复制一张 PNG 截图
  2. 在笔记里 Ctrl+V
  3. 自动出现 ![[assets/images/xxx.webp]]，且文件是 WebP → 成功 ✅

6. 常见问题

  • 不转换：检查安全模式是否关闭、预设是否选对、格式是否为 WebP
  • 画质差：把 Quality 调到 80–85
  • 找不到图片：确认 assets/images 文件夹存在、路径填写正确
