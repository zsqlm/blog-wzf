最终格式是这个 固定格式：

1

[红楼梦解读](/文件夹名/hong-lou-meng-jie-du)

也就是：

  • 链接文字 = 笔记的 title 属性
  • 链接地址 = /父文件夹/slug

1、安装Templater插件

设置≫第三方插件≫搜索“Templater”，安装并启动

2、在笔记的根目录新建模板文件

  • 在笔记的根目录新建模板文件夹，比如“00-Template”
  • 在该文件夹中新建笔记，比如“插入自定义路径链接/” 复制下面完整代码粘贴进去（完美适配你需求）：

// 选取库内所有md文件
const files = app.vault.getMarkdownFiles();
const targetFile = await tp.system.suggester(f => f.basename, files);
if (!targetFile) return;

// 读取frontmatter
const cache = app.metadataCache.getFileCache(targetFile);
const fm = cache.frontmatter ?? {}; 

// 取值：title / slug / 文件夹
const title = fm.title || targetFile.basename;
const slug = fm.slug || targetFile.basename;
const folderPath = targetFile.parent?.path ?? "";

// 输出格式：[title](/文件夹/slug)
const link = `[${title}](/${folderPath}/${slug})`;

tR += link;
-%>

3、配置Templater插件

  • 打开 Obsidian 设置 → 第三方插件 → 打开 Templater 设置
  • 找到：Template folder location
    • 手动填写一个文件夹，比如：00-Template
  • 找到：Trigger on new file creation 关掉（不需要）
  • 保存

4、调用模板

  • 打开任意笔记
  • 按下ALT+E（默认快捷键），可以设置成自己的快捷键
  • 选择：插入自定义路径链接
  • 弹窗选择目标笔记 → 自动插入结果 输出示例：
1

[红楼梦解读](/book/hong-lou-meng)

<%*
// 选取库内所有md文件
const files = app.vault.getMarkdownFiles();
const targetFile = await tp.system.suggester(f => f.basename, files);
if (!targetFile) return;

// 读取 frontmatter
const cache = app.metadataCache.getFileCache(targetFile);
const fm = cache.frontmatter ?? {};

// 基础取值
const title = fm.title || targetFile.basename;
let slug = fm.slug || targetFile.basename;

// 增强处理：去除空格 + 强制全小写
slug = slug.replace(/\s+/g, "").toLowerCase();

// 获取文件夹路径
const folderPath = targetFile.parent?.path ?? "";

// 最终链接：[title](/目录/处理后slug)
const link = `[${title}](/${folderPath}/${slug})`;

tR += link;
-%>

<%*
const files = app.vault.getMarkdownFiles();
const targetFile = await tp.system.suggester(f => f.basename, files);
if (!targetFile) return;

const cache = app.metadataCache.getFileCache(targetFile);
const fm = cache.frontmatter ?? {};

const title = fm.title || targetFile.basename;
let slug = fm.slug || targetFile.basename;

// 强效净化：去空格、仅保留字母数字-、小写
slug = slug
  .replace(/\s+/g, "")
  .replace(/[^a-zA-Z0-9\-]/g, "")
  .toLowerCase();

const folderPath = targetFile.parent?.path ?? "";
const link = `[${title}](/${folderPath}/${slug})`;

tR += link;
-%>
