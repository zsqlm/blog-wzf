Hugo Stack主题如何在内容页添加分类、标签云

在 Stack 主题里，内容页（single）默认右侧边栏只有 TOC，你要把分类、标签云也加到内容页侧边栏，和主页一样，只需改配置 + 加模板（可选）。下面直接给可复制、能生效的完整步骤。

一、先改配置：开启内容页侧边栏组件（必做）

打开 config/_default/params.toml（或 hugo.yaml），找到 widgets.page，把 categories、tag-cloud 加进去：

[widgets]
  # 首页侧边栏（保持你原来的）
  homepage = [
    { type = "archives", params = { limit = 10 } },
    { type = "categories", params = { limit = 10 } },
    { type = "tag-cloud", params = { limit = 20 } }
  ]

  # 内容页侧边栏：加上 categories、tag-cloud
  page = [
    { type = "toc", params = { keepExpanded = true } },
    { type = "categories", params = { limit = 10 } },   # 分类
    { type = "tag-cloud", params = { limit = 20 } }      # 标签云
  ]

widgets:
  homepage:
    - type: archives
      params:
        limit: 10
    - type: categories
      params:
        limit: 10
    - type: tag-cloud
      params:
        limit: 20
  page:
    - type: toc
      params:
        keepExpanded: true
    - type: categories
      params:
        limit: 10
    - type: tag-cloud
      params:
        limit: 20

保存后重启 hugo server，访问文章页，右侧边栏就会出现分类、标签云，和主页完全一样。

二、想 “和主页样式完全一致”（可选，覆盖模板）

如果上面配置后，你觉得内容页的分类 / 标签云样式和主页有差异，可以复制主题自带的 widget 模板到你的项目，强制统一。

1. 复制主题模板到你的项目

从主题目录复制这 2 个文件：

1
2

themes/hugo-theme-stack/layouts/partials/widget/categories.html
themes/hugo-theme-stack/layouts/partials/widget/tag-cloud.html

放到你项目的对应目录（没有就新建）：

1
2

layouts/partials/widget/categories.html
layouts/partials/widget/tag-cloud.html

2. 不用改代码，直接生效

Stack 会优先加载你项目里的模板，这样首页、内容页的分类 / 标签云就会完全同构、同样式。

三、常见坑（你可能遇到的）

  1. 改了不生效：
    • 路径必须是 config/_default/params.toml
    • 改完必须 重启 hugo server（不能只刷新）
  2. 只显示当前文章的分类 / 标签，不是全站：
    • Stack 的 categories/tag-cloud widget 默认就是全站聚合，不是单篇的。
    • 如果你想要单篇文章的分类 / 标签（在标题下），那是另一个组件，下面补充。

四、补充：在文章标题下方显示 “当前文章的分类 + 标签”

如果你要的是内容页标题下面（不是侧边栏）显示当前文章的分类、标签：

{{ define "main" }}
<article class="article">
  <header class="article-header">
    <h1>{{ .Title }}</h1>
    <!-- 当前文章的分类 -->
    {{ with .Params.categories }}
    <div class="article-categories">
      {{ range . }}
        <a href="{{ "categories/" | relLangURL }}{{ . | urlize }}/">{{ . }}</a>
      {{ end }}
    </div>
    {{ end }}
    <!-- 当前文章的标签 -->
    {{ with .Params.tags }}
    <div class="article-tags">
      {{ range . }}
        <a href="{{ "tags/" | relLangURL }}{{ . | urlize }}/">{{ . }}</a>
      {{ end }}
    </div>
    {{ end }}
  </header>
  <div class="article-content">
    {{ .Content }}
  </div>
</article>
{{ end }}

五、最终效果

  • 侧边栏：和主页一样，显示全站分类、全站标签云（由配置控制）。
  • 标题下方：显示当前文章所属分类、标签（由 single.html 控制）。
