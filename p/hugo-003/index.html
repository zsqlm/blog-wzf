Hugo Stack 主题：目录 _index.md 完整 SEO 优化方案

_index.md 是栏目页 / 目录列表页（分类、文集、子目录首页），是 Hugo 里极容易忽略的 SEO 流量入口，Stack 主题完全支持自定义栏目页 TDK、收录、结构化、爬虫优化，直接照着配置即可。

一、核心：_index.md 标准 SEO 头信息（直接复制即用）

不管是 posts/cat-01/_index.md、docs/_index.md 任意层级目录，通用 Front Matter：

---
title: "分类一｜优质文章合集"
# 1. SEO 标题（搜索引擎展示标题，比标题更短、带关键词）
seo_title: "分类一 - 高质量干货文章合集｜个人博客"
# 2. 描述（必写，抓取摘要，提升点击）
description: "这里收录分类一全部原创文章，持续更新干货内容，内容完整、阅读友好，方便集中查阅学习。"
# 3. 关键词（精简3-8个）
keywords: "分类一,干货文章,笔记合集,学习记录"
# 4. 发布/更新时间
date: 2026-01-01T00:00:00+08:00
lastmod: 2026-05-05T12:00:00+08:00
# 5. 爬虫规则（重点）
robots: "index,follow"
# 6. 排序、侧边栏菜单
weight: 1
# 7. 缩略图/OG 社交分享图
cover: "/images/seo/cat01-cover.jpg"
# 8. 关闭评论（栏目页没必要开评论）
comment: false
# 9. 面包屑、结构化数据适配
breadcrumb: true
---

二、Stack 主题专属关键配置（决定是否生效）

1. 开启栏目页 SEO 抓取

Stack 默认会读取页面 description / seo_title，只需在全局配置开启：

打开 config/_default/params.toml

1
2
3
4
5
6
7

# 允许 section 目录页输出 meta 描述
section_meta = true
# 开启 OG / Twitter 社交标签（利于收录+外链权重）
og = true
twitter_card = true
# 自动生成摘要
auto_summary = true

2. 区分：需要收录 / 禁止收录 目录

  • 需要收录（分类、文集、教程栏目）

    robots: "index,follow"

  • 不需要收录（隐私、归档、草稿、无用目录）

    robots: "noindex,nofollow"

三、解决 3 个 _index.md 常见 SEO 硬伤

问题 1：目录页内容空洞、被判定低质

✅ 解决方案：

  1. 在 _index.md 正文写200～500 字原创栏目介绍
  2. 自然植入栏目核心关键词、长尾词
  3. 不要只留空白，空白栏目页极易被降权

问题 2：栏目页 Title 重复、太短

✅ 解决方案：

强制用 seo_title 自定义，格式模板：

栏目名称 - 核心词 | 站点名称

问题 3：层级目录 URL 不标准化

Hugo 原生目录 URL 天然友好，额外加 2 项：

  1. 全局开启规范链接 canonical

    config/_default/config.toml

1
2

canonifyURLs = true
relativeURLs = false
  1. Stack 会自动给 _index.md 生成独立 canonical 链接，避免内容重复

四、进阶 SEO 优化（目录页加分项）

1. 手动添加自定义 meta 标签

如果需要额外 meta（作者、版权、主题标签），Stack 支持页面内追加：

在 _index.md 头部增加：

1
2
3
4
5
6
7

---
# 原有配置不变
custom_meta = [
  { name = "author", content = "你的昵称" },
  { name = "copyright", content = "原创内容，禁止转载" }
]
---

2. 目录页加入 结构化数据（Schema）

Stack 自动识别 Section 栏目页，输出 CollectionPage 结构化数据；

只要补全 description、cover，搜索引擎会自动识别为文章合集，提升展示权重。

3. 站点地图包含目录页

确保 config/toml 开启：

1
2
3

[sitemap]
  enable = true
  includeSections = true  # 关键：让 _index.md 目录页进入站点地图

作用：Google / 百度 快速抓取所有多级栏目目录。

五、多级目录通用复用规则

你现在的结构：

1
2

content/posts/cat-01/_index.md
content/posts/cat-01/sub/_index.md
  • 每一层级 _index.md 都单独写独立 TDK
  • 下级目录关键词做差异化，不要和上级完全重复
  • 父目录做大分类，子目录做细分长尾，形成栏目矩阵
